# تطبیق با تمام بندهای صورت سؤال

منبع: `Last.pdf`، یک صفحه، پروژهٔ فروشگاه تلگرام. اجرای این پروژه از ربات تحلیل بازارِ مکالمهٔ قبلی مستقل است.

| بند صورت سؤال | پیاده‌سازی | مسیر امتحان |
|---|---|---|
| ثبت‌نام و ورود با شمارهٔ تلفن | Contact خود فرستنده، ثبت شماره و ورود پایدار؛ خروج با `/logout` | `/start` ← اشتراک شماره |
| دسته‌بندی و دکمه‌های محصولات هر دسته | جدول categories و منوهای صفحه‌بندی‌شده | محصولات ← دسته ← کالا |
| افزودن به سبد و نمایش قیمت نهایی | تعداد، حذف، جمع دقیق، کد تخفیف و پیش‌نمایش نهایی | سبد خرید ← نهایی‌کردن |
| مشاهدهٔ سفارش‌ها و وضعیت ارسال | تاریخچهٔ فقط متعلق به همان مشتری | سفارش‌های من ← شمارهٔ سفارش |
| جست‌وجوی نام محصول | جست‌وجوی بخشی از نام با پارامتر SQL | جستجوی محصول یا فرستادن نام |
| صدور کد تخفیف بعد از خرید | کد شخصی ۱۰٪، یک‌بارمصرف، برای خرید بعدی | خرید اول ← کدهای تخفیف من ← خرید دوم |
| ارسال تیکت برای ادمین | ذخیرهٔ سؤال و اعلان برای ادمین‌ها | پشتیبانی ← ارسال تیکت |
| پاسخ، بلاک و آنبلاک در تیکت‌ها | کنترل نقش ادمین، پاسخ ذخیره‌شده و اعلان | `/admin` ← تیکت‌ها |
| افزودن، حذف و ویرایش محصول | ورودی مرحله‌ای، تأیید حذف، حفظ سفارش قدیمی | `/admin` ← مدیریت محصولات |
| اطلاع‌رسانی تخفیف‌ها و سفارش‌ها | اطلاعیهٔ گروهی با پیش‌نمایش؛ اعلان سفارش و تخفیف شخصی | ارسال اطلاعیه و مدیریت سفارش‌ها |
| وضعیت پردازش، ارسال، تحویل | انتقال ترتیبی و اعلان مشتری | مدیریت سفارش‌ها ← سفارش ← وضعیت بعدی |
| مدیریت موجودی و اعلان صفر به مثبت | تنظیم موجودی، فهرست متقاضیان و اعلان هنگام موجودشدن | کالای ناموجود ← خبرم کن؛ ادمین ← تنظیم موجودی |

## فرض‌های روشن

- منظور از خرید در نسخهٔ آموزشی، ثبت قطعی سفارش با پرداخت هنگام تحویل است؛ صورت سؤال درگاه یا روش پرداخت تعیین نکرده است.
- ارسال رایگان انتخاب شده و قبل از تأیید به مشتری نشان داده می‌شود.
- کد تخفیف پس از ثبت سفارش صادر می‌شود و برای سفارش بعدی قابل استفاده است؛ اعتبار ۳۰ روز و درصد ۱۰ انتخاب‌های این پیاده‌سازی‌اند.
- اعلان موجودشدن فقط برای کسانی ارسال می‌شود که دکمهٔ درخواست اعلان همان کالا را زده باشند.
- احراز شماره از Contact متعلق به حساب Telegram انجام می‌شود؛ سرویس پیامک جداگانه استفاده نمی‌شود.
- عکس محصول، پرداخت آنلاین، لغو/مرجوعی، گزارش حسابداری و پنل وب در این صورت سؤال نیستند و ادعای پیاده‌سازی آن‌ها نشده است.
